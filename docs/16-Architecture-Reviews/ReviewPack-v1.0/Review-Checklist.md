# Architecture Review Checklist

The reviewer is requested to evaluate the following areas.

## Domain Integrity

- Entity correctness
- Value Object correctness
- Aggregate boundaries
- Repository boundaries
- Domain Service responsibilities
- Domain Event correctness

---

## Ubiquitous Language

- Naming consistency
- Domain terminology
- Semantic clarity

---

## Tactical DDD

- Aggregate invariants
- Transaction boundaries
- Repository correctness
- Event consistency

---

## Architecture

- Coupling
- Cohesion
- Scalability
- Future evolution

---

## Business

- Commercial reasoning
- Explainability
- Evidence lineage
- Executive sovereignty
